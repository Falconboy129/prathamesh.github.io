Overview

Conventional myoelectric prosthetic arms cost upward of $20,000, putting them out of reach for most people who need them. This project set out to prove that a functional, AI-assisted prosthetic forearm could be built for under $200 using off-the-shelf components and open-source tools.

Most commercial prosthetics rely on fixed, factory-calibrated signal thresholds that treat every user identically — but neuromuscular signals vary by anatomy, muscle condition, and fatigue, which is a major contributor to the 26–45% abandonment rate seen across upper-limb prosthetics. This system instead uses a Random Forest classifier trained on each user's own EMG signal patterns, so the hand adapts to the person wearing it instead of forcing the person to adapt to the device.

The current build is a proof-of-concept focused on validating the signal-to-motion pipeline: EMG acquisition, on-device classification, and coordinated servo actuation, as a foundation for future clinical refinement and patient-specific customization.

How It Works

EMG Sensing (MyoWare)

Surface EMG electrodes wired to MyoWare muscle sensors are placed on the forearm to capture the neuromuscular signals produced by muscle contractions in the residual limb. These raw signals represent user intent and serve as the physiological input to the whole control system.

ESP32 Acquisition & Filtering

An ESP32 microcontroller acquires the EMG signal in real time, applies basic filtering, and validates the data for safety and consistency before passing it over serial to the Raspberry Pi for higher-level processing.

Feature Extraction

Raw EMG data is noisy on its own, so the pipeline computes features like Mean Absolute Value (MAV) and Root Mean Square (RMS) over short signal windows, converting muscle activity into numerical inputs the classifier can act on in milliseconds.

Random Forest Classifier

A Random Forest model trained on the Raspberry Pi learns each user's individual EMG signatures for every intended grip, rather than relying on one-size-fits-all thresholds. It adapts to signal variation across sessions and fatigue, and improves in accuracy the more it's used, eliminating manual recalibration.

Raspberry Pi — Signal Smoothing & Intent Classification

The Pi runs advanced signal smoothing alongside the in-house-trained Random Forest model, reducing noise and translating classified muscle patterns into high-level movement commands before sending them onward for actuation.

Servo Actuation & Mechanical Structure

Validated movement commands drive five servo motors (MG996-class), one per finger, connected through a pulley-and-string tendon mechanism. The hand and finger linkages are 3D printed, and the tendon routing replicates natural finger flexion and extension for coordinated, responsive grip motion.

Signal flow: MyoWare EMG sensor → ESP32 (acquisition + filtering) → Raspberry Pi (feature extraction, Random Forest classification, signal smoothing) → servo control commands → five pulley-driven servos actuating the fingers.

Challenges & Current Status

Raw EMG signal is inherently noisy, and muscle patterns shift between sessions and with fatigue — the core challenge this project targets by replacing fixed thresholds with a classifier that adapts per user instead of requiring the user to adapt to the device. Getting the tendon-and-pulley routing to reliably reproduce natural finger curl also took several print iterations to dial in.

The current build is a proof-of-concept prioritizing system architecture validation, signal fidelity, and mechanical feasibility. Next steps include further clinical refinement and deeper patient-specific customization of the classifier.
